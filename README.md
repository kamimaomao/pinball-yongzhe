# 弹珠勇者 · 弹夹撞击闯关录（Pinball Brave: Slingshot RPG）

将《福福神仙弹珠录》的**拉弓弹射撞击小队 RPG 底座**（反射壁咚 vs 贯通弱点、碰撞队友友情技、号令与天罚五大必杀、场内三阶成长补给与碰柱反弹、主线闯关 + 四人编队羁绊 + 宝箱招募 + 全图鉴养成）与本仓库 **《闯关勇者》REA 解包资产及配置表**深度缝合的独立 Web 游戏工程。

## 资产缝合与零残留说明

- **零原项目资产残留**：100% 剔除原弹珠底座中的 `.webp` 贴图与旧项目设定文案，绝无任何原项目资产残留。
- **不新增外部栅格资产 + 最大化压榨 REA 解包库（共接入 280+ 项原生素材）**：
  - **54 位可上阵角色全图鉴**：完整收录 `db.full.json` 中的 **10 位起源勇者**（`role_1..10`）、**17 套觉醒神装**（`skin_1..17`）、**9 只契约魔宠**（`pet_icon_*`）、**9 骑传奇坐骑**（`ride_skin_*`）与 **9 位降服魔王**（`moster_3_*`）；
  - **敌我全员实装 `_st` 受击颜艺差分帧**：弹珠撞击魔物、首领或敌弹命中我方勇者时，实时切换为原版 `_st.png` 挨揍表情并配合挤压微抖与 `Hud/shouji.png` 受击爆点（详情弹窗内点击立绘亦可直接切换预览颜艺）；
  - **原版子弹友情技 & 必杀大招飞弹**：撞击队友发射 `Bullets/zidan_1..10`、`zidanshu_11..12` 原版子弹切帧，终极必杀发射 `Bullets/dazhao_1..10,21` 巨型飞弹并叠加 `effect/` 技能光效；
  - **原版 `treasureDB` 宝物二合一神话合成**：还原 `魔法鸡腿 + 魔杖 = ★鸡腿法杖`、`图腾 + 怒火 = ★狂暴图腾` 等 8 组彩色神话神器自动融合与 `Treasures/` 合成台界面；
  - **原版 `Hud/` 彩色位图伤害跳字 + `fz.ttf` 字体 + 全 31 轨 MP3 配乐音效**：完整接入 `PT_ / BJ_ / HX_ / JN_ / FS_ / DZ_` 位图数字跳字、4 首场景 BGM 与 27 首战斗/合成/开箱音效。
- **SVG 过渡指示件（`src/svg_fallbacks.js`）**：针对原解包图集中无 1:1 现成切图的五大元素克制纹章、弹珠「反射/贯通」角标、BOSS 旋转弱点准星及顶栏声音开关，统一采用轻量矢量 SVG 过渡。

## 本地运行与独立发布包构建

构建独立自包含静态包 `pinball/dist/`：

```bash
node pinball/tools/build_dist.mjs
```

在仓库根目录启动防断连本地静态服务：

```bash
node pinball/tools/serve.mjs 8890
```

浏览器打开：`http://127.0.0.1:8890/pinball/`（或独立发布包 `http://127.0.0.1:8890/pinball/dist/`）。
